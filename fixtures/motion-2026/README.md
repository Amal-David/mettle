# Live Figma style-placement fixture

Captured September 30, 2026 from `flxINzepb5BgRcRfGj0Tl5`, frame `13:2`. Four nodes contain stacked position/opacity styles, scale, rotation and Back easing. This is diagnostic artwork, not a product showcase.

`styles.source.json` preserves source geometry, values, operation order, exact curves, local key times and style placement. Only style props were omitted from this compact fixture; the live source snapshot fingerprint was independently returned as `a7bea2c9` and is checked before compiling. The exporter's normal capture preserves full style metadata.

`styles.figmetal.json` is generated by `node scripts/compile_motion_fixture.mjs` and must not be edited by hand. `figma-css-reference.txt` is independently generated by Figma's `get_motion_context` tool for the stacked node, whitespace reformatted. Swift tests check the corresponding source values/times, not images recreated by our own renderer.

The styles are Figma-authored with configured parameters. Opaque custom IDs are additionally covered by unit tests. This does not establish pixel parity for arbitrary user-authored custom styles, rotation/scale pivots or the upcoming text/audio features.
